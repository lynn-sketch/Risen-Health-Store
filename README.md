## Run locally

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (usually http://localhost:5173).

## Features

- Full product catalogue from your materials
- Cart + WhatsApp checkout (MTN / Airtel ready messaging)
- Wishlist & product compare (saved in browser)
- Smart Health Quiz recommendations
- Search, category filters & sorting
- Order tracking demo, FAQ, delivery info
- Mobile-responsive design with floating WhatsApp CTA
